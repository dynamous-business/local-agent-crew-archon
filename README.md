# Local agent crew on Archon

This repository is a standalone copy of [Archon](https://github.com/coleam00/Archon) (MIT licence) used for one experiment:
a crew of local AI agents, running Qwen3.8-Flash-Next on an ASUS ProArt P16, works through copies of Archon's GitHub issues.

- The code is on the `dev` branch. Each crew fix is a `crew/issue-N` branch with a PR against `dev`.
- Issues here are copies of upstream issues, with every @mention and issue reference defused, so nothing in this
  repository notifies anyone or links back to the real Archon repository.
- Nothing here is merged upstream. Every PR needs a human review.

The setup, the workflow and the measured results are in the companion repository.
